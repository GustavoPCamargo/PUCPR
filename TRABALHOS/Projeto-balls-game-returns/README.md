## Como executar o projeto

1. Certifique-se de que todos os arquivos do jogo estejam na mesma pasta:

   * `index.html`
   * `sketch.js`
   * `style.css`
   * `ship1.png`
   * `ship2.png`
   * `fundo.jpg`
   * `moeda.mp3`
   * `powerup.mp3`
   * `musica.mp3`
   * (quaisquer outras imagens ou sons usados)

2. Abra o arquivo **index.html** em um navegador.

   * Recomendado: Chrome.
   * Se algum som não tocar, clique com o mouse na tela para liberar o áudio.

3. Caso esteja usando **VSCode**, recomenda-se usar a extensão *Live Server* para evitar erros ao carregar arquivos.

## Como jogar

### Menu

* **1** → Modo 1 Jogador
* **2** → Modo 2 Jogadores
* **S** → Tela de Sobre
* **ENTER** → Voltar ao menu quando estiver na tela de fim ou sobre

---

## Controles

### Player 1

* **Seta para Cima** → Acelerar
* **Seta para Direita** → Girar para a direita
* **Seta para Esquerda** → Girar para a esquerda

### Player 2 (modo 2 jogadores)

* **W** → Acelerar
* **D** → Girar para a direita
* **A** → Girar para a esquerda

---

## Objetivo

Pegue o máximo de moedas antes que o tempo acabe.

* Moeda amarela → 1 ponto
* Moeda roxa (especial) → 2 pontos

---

## Power-Ups

Aparecem automaticamente a cada 7 segundos.

* **Verde (2x)** → Dobra seus pontos por 5 segundos
* **Azul (2v)** → Dobra sua velocidade por 10 segundos

Toque no power-up para ativá-lo.

---

## Sons

* `moeda.mp3` → quando uma moeda é coletada
* `powerup.mp3` → quando um power-up é ativado
* `musica.mp3` → fica em loop durante o jogo

---

## Tela de fim

Mostra a pontuação dos jogadores. Pressione **ENTER** para voltar ao menu.
